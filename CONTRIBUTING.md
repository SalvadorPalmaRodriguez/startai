# Contributing to startai

startai is **source-visible proprietary software** ([LICENSE](LICENSE)). The
source code is public so you can read, audit and use it for personal use — but
it is not an open-source project.

## Code contributions

**Code contributions are not accepted.** Pull requests containing code will be
closed. The license does not permit derivative works, and the project does not
operate a contributor license agreement.

## What IS welcome

- **🐛 Bug reports** — open an issue. Please include your OS, Python version and
  the exact command and output.
- **💡 Feature suggestions** — open an issue describing the use case, or write
  to salvadorpalmarodriguez@gmail.com.
- **📚 Documentation feedback** — typos, unclear explanations or outdated
  examples: open an issue.
- **🔐 Security reports** — **email only**, never public issues. See
  [SECURITY.md](SECURITY.md). Reporting within 72 hours of discovery is
  required by the license (§5).
