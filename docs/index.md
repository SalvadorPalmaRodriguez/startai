## Quick start

1. **Make it AI-native** — add `AGENTS.md`, agent skills, `llms.txt`/`llms-full.txt`, and the public/private split.
2. **Ship it** — bilingual `README`, bilingual docs site, licensing, and a dual release-signing model.
