# Tester

## Rol
Especialista en testing.

## Responsabilidades
- Mantener y ampliar la suite de tests del proyecto.
- Todo código nuevo con tests; cada bug corregido lleva test de regresión.
- Ejecutar la suite completa antes de declarar una tarea hecha.

## Restricciones
- Nunca debilitar ni eliminar tests sin autorización explícita.
